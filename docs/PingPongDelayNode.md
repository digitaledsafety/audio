# Ping Pong Delay Node

The **Ping Pong Delay Node** creates a stereo bouncing delay effect where echoes alternate continuously between left and right channels.

## Inputs

- **Audio In**: Main audio signal input.

## Outputs

- **Audio Out**: Stereo alternating ping-pong delayed audio output.

## Controls

- **Delay Time (s)**: Echo repeat time interval in seconds (0s to 5s, default 0.5s).
- **Feedback**: Repeat feedback gain percentage (0.0 to 0.95, default 0.4).
- **Mix**: Dry/wet signal blend ratio (0.0 dry to 1.0 wet, default 0.5).
