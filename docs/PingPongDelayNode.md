# Ping Pong Delay Node (`PingPongDelayNode`)

Stereo delay effect that bounces echoes alternately between Left and Right channels.

## Inputs
* **Audio In**: Input audio signal.
* **Time CV**: Control voltage for delay time.

## Outputs
* **Audio Out**: Stereo ping-pong delay output.

## Controls
* **Time**: Delay time in seconds (0.01s to 2.0s).
* **Feedback**: Delay repetition feedback amount (0.0 to 0.95).
* **Mix**: Dry/wet mix ratio (0.0 to 1.0).

## Description
Creates alternating left-right spatial echoes.
