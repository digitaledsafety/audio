# Ping Pong Delay Node

The **Ping Pong Delay Node** creates bouncing stereo echoes that alternate between left and right output channels with configurable delay time and feedback.

## Inputs

- **Audio In**: Main audio signal input.
- **Delay CV**: Control voltage input to modulate delay time.

## Outputs

- **Audio Out**: The stereo ping-pong delayed audio output.

## Controls

- **Time (s)**: Echo delay time per bounce (0.01 s to 2.0 s, default 0.3 s).
- **Feedback**: Echo repetition decay factor (0.0 to 0.9, default 0.4).
- **Mix**: Dry/Wet blend slider (0.0 to 1.0, default 0.5).
