# DTS Enhancer Node (`DTSEnhancerNode`)

Spatial psychoacoustic audio enhancer providing surround field depth and presence.

## Inputs
* **Audio In**: Input audio signal.

## Outputs
* **Audio Out**: Enhanced stereo audio output.

## Controls
* **Depth**: Stereo depth enhancement slider (0.0 to 1.0).
* **Presence**: High-frequency clarity and presence slider (0.0 to 1.0).

## Description
The DTS Enhancer processes audio through spatial psychoacoustic filters to expand stereo width and elevate harmonic clarity.
