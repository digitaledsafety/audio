# Signal Inverter Node (`SignalInverterNode`)

Inverts the polarity of control voltages or audio signals.

## Inputs
* **In**: Input signal or control voltage.

## Outputs
* **Out**: Inverted signal output (-1 * Input).

## Controls
* None.

## Description
The Signal Inverter flips positive voltages to negative and vice versa. Useful for inverted modulation envelopes, sidechain ducking logic, or phase flipping.
