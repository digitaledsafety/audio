# Signal Inverter Node

The **Signal Inverter Node** (labeled as **Inverter**) phase-inverts an incoming audio or control voltage signal by multiplying its amplitude by -1 (180-degree phase shift).

## Inputs

- **Signal In**: The input audio or control voltage signal to be inverted.

## Outputs

- **Signal Out**: The inverted output signal.

## Controls

The Signal Inverter Node operates purely through linear phase inversion and does not require manual control parameters.
