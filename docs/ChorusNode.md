# Chorus Node

The **Chorus Node** produces a rich, shimmering ensemble effect by mixing the original audio signal with modulated pitch-shifted delay lines.

## Inputs

- **Audio In**: The incoming audio signal to be processed.
- **Rate CV**: Optional control voltage input to dynamically modulate the LFO rate.

## Outputs

- **Audio Out**: The processed stereo chorus audio signal.

## Controls

- **Rate (Hz)**: Sets the speed of the internal modulation LFO (0.1 Hz to 10.0 Hz).
- **Depth**: Sets the depth of the modulation delay time (0.0 to 1.0).
- **Mix**: Balances the dry input signal with the wet chorus effect (0.0 to 1.0).
