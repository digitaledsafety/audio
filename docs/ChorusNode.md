# Chorus Node

The **Chorus Node** applies a modulated short delay effect to simulate multiple unison voices, creating spatial depth and harmonic richness.

## Inputs

- **Audio In**: Main audio signal input.
- **Rate CV**: Control voltage input to modulate modulation LFO rate.

## Outputs

- **Audio Out**: Wet/dry chorused stereo/mono audio output.

## Controls

- **Rate (Hz)**: Sets modulation rate of the internal chorus LFO (0.1 Hz to 10 Hz, default 1.5 Hz).
- **Depth (s)**: Sets modulation depth/excursion range (0s to 0.01s, default 0.002s).
- **Delay (s)**: Sets base delay time (0.01s to 0.1s, default 0.030s).
- **Mix**: Dry/wet signal blend ratio (0.0 dry to 1.0 wet, default 0.5).
