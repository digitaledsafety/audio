# Chorus Node

The **Chorus Node** produces a rich, shimmering modulation effect by blending the original signal with modulated delayed copies using internal LFO phase-shifting.

## Inputs

- **Audio In**: Main audio signal input.
- **Rate CV**: Control voltage input to modulate LFO rate dynamically.

## Outputs

- **Audio Out**: The chorus-processed audio output signal.

## Controls

- **Rate (Hz)**: Modulation rate control (0.1 Hz to 10 Hz, default 1.5 Hz).
- **Depth**: Modulation intensity control (0.001 to 0.02 seconds, default 0.005 s).
- **Mix**: Dry/Wet mix balance control (0.0 to 1.0, default 0.5).
