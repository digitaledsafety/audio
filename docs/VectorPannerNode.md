# Vector Panner Node

The **Vector Panner Node** positions mono or stereo audio in a 2D quadraphonic/spatial sound field using X and Y coordinate controls.

## Inputs

- **Audio In**: The incoming audio signal to pan spatially.

## Outputs

- **Audio Out**: The spatially panned stereo audio output.

## Controls

- **X (Left/Right)**: Sets horizontal panning from -1.0 (Left) to +1.0 (Right).
- **Y (Front/Rear)**: Sets vertical/depth position from -1.0 (Rear) to +1.0 (Front).
