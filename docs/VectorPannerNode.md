# Vector Panner Node

The **Vector Panner Node** enables 2D spatial trajectory placement and panning across two-dimensional X (Left/Right) and Y (Front/Back) coordinates with optional control voltage modulation.

## Inputs

- **Audio In**: Main audio signal input.
- **X CV**: Control voltage input for modulating horizontal X-axis spatial position.
- **Y CV**: Control voltage input for modulating vertical Y-axis spatial position.

## Outputs

- **Audio Out**: Processed spatialized audio output.

## Controls

- **X (Left/Right)**: Horizontal coordinate positioning slider (-5.0 Left to +5.0 Right, default 0.0 Center).
- **Y (Front/Back)**: Vertical coordinate positioning slider (-5.0 Back to +5.0 Front, default 0.0 Center).
