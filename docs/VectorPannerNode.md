# Vector Panner Node (`VectorPannerNode`)

2D quad/surround vector panner for dynamic 2D spatial positioning across X and Y axes.

## Inputs
* **Audio In**: Input audio signal.
* **X CV**: Control voltage input for horizontal pan position (-1.0 to 1.0).
* **Y CV**: Control voltage input for vertical pan position (-1.0 to 1.0).

## Outputs
* **Out LF**: Left-Front output channel.
* **Out RF**: Right-Front output channel.
* **Out LR**: Left-Rear output channel.
* **Out RR**: Right-Rear output channel.

## Controls
* **Pan X**: Horizontal pan position slider (-1.0 to 1.0).
* **Pan Y**: Vertical pan position slider (-1.0 to 1.0).

## Description
Pans audio in a 2D Cartesian plane using quadraphonic output channels, allowing full spatial movement.
