# Vector Panner Node

The **Vector Panner Node** provides 2D spatial positioning across X (Left/Right) and Y (Front/Back) coordinate space.

## Inputs

- **Audio In**: Main audio signal input.
- **X CV**: Control voltage input modulating horizontal X-axis position.
- **Y CV**: Control voltage input modulating vertical/depth Y-axis position.

## Outputs

- **Audio Out**: Spatially panned output signal.

## Controls

- **X (Left/Right)**: Horizontal balance position (-5 Left to +5 Right, default 0 Center).
- **Y (Front/Back)**: Vertical/depth position (-5 Back to +5 Front, default 0 Center).
