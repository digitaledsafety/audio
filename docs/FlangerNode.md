# Flanger Node (`FlangerNode`)

Jet-plane sweeping comb filter modulation effect.

## Inputs
* **Audio In**: Input audio signal.
* **Rate CV**: Control voltage for LFO rate.

## Outputs
* **Audio Out**: Stereo flanger audio output.

## Controls
* **Rate**: Modulation speed in Hz (0.1 to 10.0 Hz).
* **Depth**: Sweep depth slider (0.0 to 1.0).
* **Feedback**: Comb filter feedback slider (0.0 to 0.95).
* **Mix**: Dry/wet mix ratio (0.0 to 1.0).

## Description
Combines input signal with a short LFO-swept delayed copy to produce characteristic jet-engine sweeping resonances.
