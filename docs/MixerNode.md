# Mixer Node

The **Mixer Node** is a 4-channel audio utility that sums up to four independent input channels into a composite stereo output, with per-channel gain, pan, and CV modulation inputs.

## Inputs

- **In 1 - In 4**: Audio inputs for channels 1 through 4.
- **Gain 1 CV - Gain 4 CV**: Control voltage inputs to modulate gain levels for each corresponding channel.
- **Pan 1 CV - Pan 4 CV**: Control voltage inputs to modulate stereo panning (-1.0 left to +1.0 right) for each corresponding channel.

## Outputs

- **Audio Out**: Master summed audio output.

## Controls

- **Gain 1 - Gain 4**: Individual channel gain sliders (0.0 to 1.0, default 0.8).
- **Pan 1 - Pan 4**: Individual channel stereo panning sliders (-1.0 Left to +1.0 Right, default 0.0 Center).
- **Master Gain**: Overall master output level slider (0.0 to 2.0, default 1.0).
