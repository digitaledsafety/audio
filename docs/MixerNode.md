# Mixer Node

The **Mixer Node** is a 4-channel audio mixer supporting per-channel level, panning, mute controls, and external CV control voltage inputs.

## Inputs

- **In 1, In 2, In 3, In 4**: Audio inputs for Channels 1 through 4.
- **Gain 1-4 CV**: CV inputs for modulating individual channel gains.
- **Pan 1-4 CV**: CV inputs for modulating individual channel stereo positions.

## Outputs

- **Audio Out**: Summed stereo mix output.

## Controls

- **Gain 1–4**: Fader level control for Channels 1–4 (0.0 to 1.0, default 0.8).
- **Pan 1–4**: Stereo panning position for Channels 1–4 (-1.0 Left to +1.0 Right, default 0.0 Center).
- **Mute 1–4**: Mute toggles for Channels 1–4 (default Unmuted/False).
