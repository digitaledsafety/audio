# Mixer Node

The **Mixer Node** sums up to 4 input audio/CV channels into a single combined output signal, with independent volume controls and CV modulation inputs for each channel.

## Inputs

- **In 1**: Audio or CV input signal for Channel 1.
- **In 1 CV**: Optional control voltage input to modulate Gain for Channel 1.
- **In 2**: Audio or CV input signal for Channel 2.
- **In 2 CV**: Optional control voltage input to modulate Gain for Channel 2.
- **In 3**: Audio or CV input signal for Channel 3.
- **In 3 CV**: Optional control voltage input to modulate Gain for Channel 3.
- **In 4**: Audio or CV input signal for Channel 4.
- **In 4 CV**: Optional control voltage input to modulate Gain for Channel 4.

## Outputs

- **Audio Out**: The summed stereo output of all active input channels.

## Controls

- **Vol 1**: Level control for Channel 1 (0.0 to 1.0).
- **Vol 2**: Level control for Channel 2 (0.0 to 1.0).
- **Vol 3**: Level control for Channel 3 (0.0 to 1.0).
- **Vol 4**: Level control for Channel 4 (0.0 to 1.0).
- **Master Vol**: Master gain control for the summed output signal (0.0 to 2.0).
