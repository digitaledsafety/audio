# Stereo Widener Node

The **Stereo Widener Node** manipulates mid/side channel levels to narrow or expand the perceived stereo width of audio signals.

## Inputs

- **Audio In**: The incoming stereo audio signal.
- **Width CV**: Optional control voltage input to modulate stereo width dynamically.

## Outputs

- **Audio Out**: The processed stereo output signal with modified width.

## Controls

- **Width**: Adjusts stereo field width from 0.0 (Mono sum) to 2.0 (Ultra-wide stereo).
