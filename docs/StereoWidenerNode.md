# Stereo Widener Node

The **Stereo Widener Node** alters the mid/side balance of an audio signal to expand or narrow the perceived spatial stereo width.

## Inputs

- **Audio In**: Main audio signal input.
- **Width CV**: Control voltage input to modulate stereo width parameter dynamically.

## Outputs

- **Audio Out**: Stereo widened output audio signal.

## Controls

- **Width**: Stereo width multiplier factor (0.0 mono / narrow to 4.0 ultra-wide, default 1.0).
- **Mix**: Dry/wet signal blend ratio (0.0 dry to 1.0 wet, default 1.0).
