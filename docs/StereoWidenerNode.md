# Stereo Widener Node (`StereoWidenerNode`)

Mid/Side stereo field widener for widening or narrowing stereo soundstage width.

## Inputs
* **Audio In**: Input audio signal.
* **Width CV**: Control voltage input for stereo width modulation.

## Outputs
* **Audio Out**: Stereo widened audio output.

## Controls
* **Width**: Stereo width slider (0.0 = Mono, 1.0 = Normal, 2.0 = Extra Wide).

## Description
Uses Mid/Side processing matrix to control stereo field expansion.
