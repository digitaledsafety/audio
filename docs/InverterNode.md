# Inverter Node

The **Inverter Node** (Signal Inverter) inverts the polarity of any incoming audio or control voltage signal by multiplying it by -1. It is useful for phase inversion, complementary envelope modulation, and differential CV routing.

## Inputs

- **Signal In**: Incoming audio signal or control voltage signal.

## Outputs

- **Signal Out**: Polarity-inverted output signal (multiplied by -1).

## Controls

The Inverter operates as a direct signal polarity utility node and requires no manual sliders.
