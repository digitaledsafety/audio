# Random Voltage Node

The **Random Voltage Node** generates stepped or smoothed random control voltage signals upon receiving clock pulse triggers.

## Inputs

- **Clock**: Trigger input to command generation of a new random voltage level.

## Outputs

- **Out**: Stepped control voltage output emitting random values (ranging from 0.0 V to 1.0 V).

## Controls

The Random Voltage node generates random voltage values automatically on incoming clock triggers.
