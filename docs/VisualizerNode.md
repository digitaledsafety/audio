# Visualizer Node

The **Visualizer Node** provides real-time audio visualization with Oscilloscope (time domain) and Spectrum Analyzer (frequency domain) modes.

## Inputs

- **Audio In**: Main audio signal input for visualization.

## Outputs

- **Audio Out**: Pass-through audio output signal.

## Controls

- **Mode**: Display visualization mode selector (`Oscilloscope` or `Spectrum`, default `Oscilloscope`).
- **Freeze / Resume**: Toggle button to freeze or resume frame rendering on the visualizer canvas.
- **Sensitivity**: Signal gain multiplier for visual display amplitude scaling (0.1x to 5.0x, default 1.0x).
