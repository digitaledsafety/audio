# Visualizer Node

The **Visualizer Node** provides real-time oscilloscope waveform, frequency spectrum analyzer, and audio signal visualization directly within node components and canvas visual overlays.

## Inputs

- **Audio In**: Signal input to analyze and visualize.

## Outputs

- **Audio Out**: Pass-through audio output allowing insertion into signal chains without signal loss.

## Controls

- **Mode**: Selects visualization display style (`Oscilloscope` waveform or `Spectrum` frequency analyzer).
- **Freeze**: Toggles waveform canvas pause/freeze for detailed analysis.
