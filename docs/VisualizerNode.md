# Visualizer Node

The **Visualizer Node** provides real-time visual monitoring of audio signals using Oscilloscope (time-domain waveform) and Spectrum Analyzer (frequency-domain FFT) displays.

## Inputs

- **Audio In**: Main audio signal input to analyze and render.

## Outputs

- **Audio Out**: Passthrough audio output signal allowing inline insertion in signal chains.

## Controls

- **Mode**: Selects visualization display rendering mode (**Oscilloscope** or **Spectrum**).
- **Freeze**: Toggles freezing/pausing the active visual frame display for inspecting static waveforms or spectral peaks.
