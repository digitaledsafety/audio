# Visualizer Node (`VisualizerNode`)

Oscilloscope and spectrum analyzer visualizer node.

## Inputs
* **In**: Input audio signal to visualize.

## Outputs
* **Out**: Passthrough audio output.

## Controls
* **Freeze**: Toggle button to pause waveform frame updates.

## Description
Renders real-time time-domain waveform or frequency spectrum visualizations on node canvas and full-screen canvas.
