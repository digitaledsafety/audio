# Clock Divider Node

The **Clock Divider Node** divides incoming master clock pulses into rhythmic sub-divisions (/2, /4, /8, /16).

## Inputs

- **Clock In**: Master clock pulse input signal.

## Outputs

- **/2**: Clock trigger output divided by 2 (half tempo).
- **/4**: Clock trigger output divided by 4 (quarter tempo).
- **/8**: Clock trigger output divided by 8.
- **/16**: Clock trigger output divided by 16.

## Controls

*None (fixed integer division outputs).*
