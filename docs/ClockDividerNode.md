# Clock Divider Node

The **Clock Divider Node** takes a master clock or rhythm pulse input and generates four synchronized, mathematically divided clock outputs (/2, /4, /8, /16). It is essential for sub-rhythms, polyrhythmic sequencing, and tempo-synchronized modulation.

## Inputs

- **Clock In**: Master clock pulse signal input.

## Outputs

- **/2**: Output firing once every 2 incoming clock ticks (half tempo).
- **/4**: Output firing once every 4 incoming clock ticks (quarter tempo).
- **/8**: Output firing once every 8 incoming clock ticks (eighth tempo).
- **/16**: Output firing once every 16 incoming clock ticks (sixteenth tempo).

## Controls

The Clock Divider operates purely from incoming clock pulses and does not require manual controls.
