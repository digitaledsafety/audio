# Compressor Node

The Compressor Node can be used to compress the dynamic range of an audio signal.

## Inputs

*   **Audio In**: The audio input to the node.
*   **Threshold CV**: Control voltage input to modulate compressor threshold.

## Outputs

*   **Audio Out**: The audio output of the node.

## Controls

*   **Threshold (dB)**: The threshold of the compressor in decibels (-60 dB to 0 dB).
*   **Knee (dB)**: The softness of the knee bend in decibels (0 dB to 40 dB).
*   **Ratio**: The compression ratio (1:1 to 20:1).
*   **Attack (s)**: The attack time of the compressor in seconds (0 s to 1 s).
*   **Release (s)**: The release time of the compressor in seconds (0 s to 1 s).
*   **Makeup Gain (dB)**: Output gain boost post-compression (0 dB to 24 dB).
